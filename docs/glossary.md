# Glossary

A comprehensive list of terms used throughout the Physical AI textbook.

## A

**Actuator** - A component of a machine that moves or controls a mechanism or system.

**AI Model** - A mathematical model designed to make predictions or decisions based on input data.

## S

**Sensor** - A device that detects and responds to physical inputs from the environment.

**SLAM** - Simultaneous Localization and Mapping, a process where a robot builds a map of an unknown environment while keeping track of its location.

## R

**Robotics** - The branch of technology that deals with the design, construction, operation, and application of robots.

## T

**TensorFlow** - An open-source platform for machine learning developed by Google.

**Transformer** - A deep learning model architecture that uses attention mechanisms to process sequential data.
